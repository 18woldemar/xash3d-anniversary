# Menu art and text: where it comes from

- `360_controller.svg`: Wikimedia Commons "360 controller.svg" by Alphathon (2010), CC BY-SA 3.0,
  <https://commons.wikimedia.org/wiki/File:360_controller.svg>, with its labels removed and its view box
  cropped. This file stays under CC BY-SA 3.0.
- Pad legend icons: rendered by `tools/mkmenu` from AL2009man/Gamepad-Asset-Pack
  (<https://github.com/AL2009man/Gamepad-Asset-Pack>, MIT, (c) 2024 Al. Lopez). Not stored here; a build that
  ships the rendered icons ships that licence with them.
- Banners and the button atlas: rendered by `tools/mkmenu` in Trebuchet MS Bold, which is Microsoft's and is
  not redistributable. The font is read from outside the repository; only the rendered images ship.
- `localization/mainui_<language>.txt`: our own translations of the menu strings the game data leaves in
  English, worded after Valve's own files for each language. Not reviewed by native speakers.
- Speech captions (`tools/mksubs`): Fograin/hl-subs-mod, free for non-commercial Half-Life mods with credit.
